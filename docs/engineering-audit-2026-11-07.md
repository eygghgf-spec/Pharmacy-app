# مراجعة هندسية — مساعدي الذكي للصيدلية والمحاسبة

## النطاق

تمت مراجعة التطبيق الحالي دون إنشاء مشروع جديد أو حذف المشروع. شملت المراجعة واجهات React Native، خادم tRPC، مخطط Drizzle، SQLite المحلي، OAuth والجلسات، الصلاحيات، المزامنة، Gemini، إعداد Expo وEAS.

## العيوب الحرجة التي تم إصلاحها في هذه المرحلة

أصبح الخادم يعيد حساب إجمالي الفاتورة من السعر الرسمي للصنف بدل الثقة بقيمة العميل، ويرفض السعر المختلف. أصبح البيع يتحقق من وجود الصنف ونشاطه، ويتحقق من ارتباط الدفعة بالصنف، ويختار الدفعات الصالحة حسب أقرب انتهاء FEFO عندما لا يرسل العميل دفعة محددة. كما يرفض الدفعة المنتهية أو الكمية غير المتوفرة ويستخدم تحديثًا مشروطًا لمنع المخزون السالب.

أضيف جدول `syncOperations` ومفتاح idempotency لمنع إعادة تنفيذ عملية المزامنة نفسها. وإذا فشلت العملية يُحرر المفتاح حتى يمكن إعادة المحاولة. أزيل الاستدعاء الفوري المكرر عند إضافة صنف محليًا، فأصبحت العملية تنتظر صندوق المزامنة بدل إنشاء سجل ثم إنشائه مرة ثانية.

أزيلت الأرقام التجريبية من لوحة الرئيسية وربطت المبيعات وعدد الفواتير وعدد الأصناف بمسار `dashboard.summary` من الخادم. فُعّلت اختصارات لوحة الرئيسية إلى شاشاتها بدل أزرار بلا وظيفة. أضيف تمرير دور المستخدم في استجابات OAuth، وأضيف فشل مبكر في بيئة الإنتاج إذا لم يُضبط سر الجلسة.

## التحقق المنفذ

نجح `pnpm check` و`pnpm lint` و`pnpm test` و`pnpm build` بعد التعديلات الحالية. الاختبارات الموجودة نجحت: 25 اختبارًا، مع اختبار تسجيل الخروج متجاوزًا. عاد API بحالة صحية، وعادت معاينة Metro بحالة HTTP 200. تم إنشاء وتطبيق migration `0003_opposite_cargill.sql` لإضافة جدول idempotency.

أُخذت نسخة احتياطية قبل تطبيق migration في ملف محلي داخل `backups/`، ولم تُضاف إلى Git لأنها تحتوي بيانات قاعدة البيانات.

## ما لم يكتمل بعد

لا تزال المشتريات والمرتجعات والمصروفات والذمم وإدارة المستخدمين وسجل التدقيق واجهات وعمليات غير مكتملة. كما أن شاشة التقارير ما زالت تحتاج ربطًا كاملًا باستعلامات حقيقية، ويجب إضافة دفعة افتتاحية من واجهة المخزون بدل حفظ صنف بلا دفعة عند العمل دون اتصال. لم يُختبر OAuth أو الصلاحيات على جهاز Android فعلي.

لم يُنشأ APK في هذه البيئة؛ إنشاء APK يتطلب تشغيل EAS Build بحساب Expo من خارج Sandbox أو من لوحة EAS. لا يوجد رابط APK يمكن تقديمه قبل اكتمال ذلك البناء.

## إعدادات خارجية مطلوبة

يلزم `DATABASE_URL` وبيانات OAuth و`JWT_SECRET` أو `MANUS_JWT_SECRET` و`GEMINI_API_KEY`، إضافة إلى حساب Expo/EAS واعتمادات توقيع Android. ويجب مراجعة الضرائب والفاتورة الإلكترونية والأدوية المقيدة حسب بلد التشغيل قبل اعتماد النظام تجاريًا.
