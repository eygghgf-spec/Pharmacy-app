# تقرير تنفيذ نظام الصيدلية — 2026-11-07

## ما تم تنفيذه

أضيفت الجداول الفعلية للموردين وفواتير الشراء وبنودها والمصروفات والمرتجعات وبنود المرتجعات وسجل التدقيق. أضيفت معاملات شراء تزيد الدفعات وتراكم رصيد المورد، ومعاملة مرتجع بيع تتحقق من الكمية المباعة وتعيد الكمية إلى الدفعة عند اختيار الإرجاع للمخزون. أضيفت مسارات محمية حسب الدور للمشتريات والمصروفات والمرتجعات والمستخدمين، مع تسجيل العمليات الحساسة في سجل التدقيق.

أضيفت شاشات عربية للمشتريات والمصروفات والمرتجعات وإدارة المستخدمين، وربطت التقارير بالمبيعات والمصروفات الحقيقية. التصميم العام واتجاه RTL والهوية الخضراء محفوظة. أضيفت اختبارات مجال للإجمالي وFEFO ورفض المخزون غير الكافي.

الإصلاحات السابقة الخاصة بإعادة حساب سعر البيع والإجمالي من الخادم ومنع المخزون السالب وidempotency للمزامنة ما زالت ضمن المشروع.

## حدود الاختبار

لم أختبر تسجيل الدخول OAuth أو كل الأدوار على جهاز Android فعلي. لم أختبر رحلة EAS أو تنزيل APK لأن بناء Android Release غير مسموح داخل Sandbox، كما أن رفع commit إلى المستودع المُدار متعطل حاليًا بسبب أداة Git credential helper مفقودة. لم تُختبر عمليات الشراء والمرتجعات تكامليًا ضد قاعدة اختبار منفصلة؛ الاختبارات الحالية لا تنفذ فواتير حقيقية لتجنب تعديل بيانات المستخدم.

## المتبقي قبل إعلان الإصدار التجاري

شاشة المشتريات الحالية تحتاج اختيارًا كاملًا للمورد والصنف وبنود متعددة. شاشة المرتجعات الحالية تحتاج بحث الفاتورة وعرض البنود بدل إدخال المعرفات. ما زالت مرتجعات المشتريات وديون العملاء وكشوف الحساب وشاشة عرض سجل التدقيق والمزامنة الدورية مع retries/backoff بحاجة إلى استكمال. يلزم أيضًا إزالة اختبار logout المتجاوز واختبار OAuth والصلاحيات على Android فعليًا.
